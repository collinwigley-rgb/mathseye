# 2.8 — Solve Problems Involving Scale Drawings

Source: Lesson 2-8 student pages, 2-8 Additional Practice (pp. 29–30) · Built: 2026-11-03

## In one sentence
A scale (1 in. = 1.5 ft) is a constant of proportionality: **actual = k × drawing**. Lengths scale by k, and **areas scale by k²** (or find the actual length and width first, then multiply).

## Key concepts and vocabulary
| Term | Plain meaning | Tiny example |
| --- | --- | --- |
| Scale drawing | A drawing that's proportional to the real object | a kitchen blueprint |
| Scale | Drawing length = actual length | 1 in. = 1.5 ft |
| Scale factor (k) | Actual units per 1 drawing unit | k = 1.5 ft per inch |
| Non-unit scale | A scale where the drawing side isn't 1 | 2 in. = 5 ft → k = 2.5 ft per inch |
| New scale | Redrawing the same object at a new size | the mascot: 1 in. = 4 ft → 1 in. = 0.5 ft |

**Big idea:** get the scale to "1 drawing unit = ? actual units." After that, every length is just ×k. Going backward (actual → drawing) is ÷k.

## Problem profile
| Type | Given → asked | Numbers | Format | Share |
| --- | --- | --- | --- | --- |
| A. Drawing → actual length | scale + drawing length → actual | k whole or decimal (1.5, 1.7, 7.2) | typed | ~30% |
| B. Non-unit scale | 2 in. = 5 ft, 3.75 in. = 24 ft → unit scale first | decimals | typed | ~15% |
| C. Area from a drawing | scale + a rectangle on the drawing (or a grid) → actual area | sq ft, sq yd, sq m; maybe × a cost per sq ft | multi-step | ~25% |
| D. New scale | old scale + a new drawing length → the new scale + other new lengths | 80-inch mural, 16.8-inch blueprint | Part A / Part B | ~20% |
| E. Maps with spacing | map distance + scale → actual, then equal spacing on a new map | rest stops, cities | higher-order | ~10% |

**Traps:** multiplying the drawing area by k (not k²); forgetting to convert the non-unit scale; counting gridlines wrong; for the rest stops, 11 stops make 10 gaps.

## Methods: ways to attack it

### Method 1: "Make it 1 inch" then multiply
1. Rewrite the scale so the drawing side is 1: 2 in. = 5 ft → 1 in. = 2.5 ft.
2. Actual = k × drawing.
3. Drawing = actual ÷ k.
**Memory hook:** "One inch first, then multiply."

### Method 2: Proportion
(drawing / actual) = (drawing / actual). Keep the SAME order on both sides, then cross-multiply.
1 in. / 1.5 ft = 6 in. / x ft → x = 9 ft.

### Method 3: Area: convert sides first
1. Change the drawing's length and width to actual lengths (×k each).
2. Multiply the actual length × width.
**Never** multiply the drawing area by k. (If you know it: area scales by k².)

### Method 4: New scale in three steps
1. Find the actual size with the old scale.
2. New scale: actual ÷ new drawing length = new k.
3. Use the new k for every other dimension (new drawing = actual ÷ new k).
**Shortcut check:** every length on the new drawing changes by the same factor (16.8 / 14 = 1.2, so the width is 12 × 1.2).

## Guiding questions (homework help)
1. "What does ONE inch (or cm) on the drawing stand for?"
2. "Are you going drawing → actual (multiply) or actual → drawing (divide)?"
3. For area: "What are the actual length and the actual width?"
4. For a new scale: "How big is the real thing? Now how many real feet per new inch?"
5. "Does your answer make sense? A real room should be bigger than its drawing."

## Common mistakes
| Mistake | What it looks like | Nudge |
| --- | --- | --- |
| Area × k | (8 × 16 cm²) × 2 instead of 32 × 16 yd² | "Turn each side into actual length first." |
| Uses a non-unit scale as k | k = 5 for 2 in. = 5 ft | "How many feet for ONE inch?" |
| Flips the proportion | in/ft = ft/in | "Same order on both sides." |
| Divides when she should multiply | real is smaller than the drawing | "Should the real thing be bigger or smaller?" |
| Gridline counting | counts lines, not spaces | "Count the gaps between lines." |
| Fence-post error | 11 stops → ÷11 | "Draw 3 stops. How many gaps?" |

## Variant recipes
- **A:** `1 unit = k`, drawing d (decimals to tenths), k in {1.5, 2, 2.5, 4, 7.2}.
- **B:** `a in. = b ft` with a ≠ 1 → actual for d inches.
- **C:** a rectangle w × l on the drawing, scale k → the actual area; add a cost per sq ft.
- **D:** an old drawing L × W at scale k1; a new length L2 → new scale k2 = (L × k1) / L2, and new width = W × L2 / L.
- **E:** map length, scale, n stops equally spaced → spacing on a new scale.

## Worked example (original)
*A garden drawing is 4 in. by 6 in. Scale: 2 in. = 3 ft. What's the actual area?*
1. Make it 1 inch: 1 in. = 1.5 ft.
2. Actual sides: 4 × 1.5 = 6 ft; 6 × 1.5 = 9 ft.
3. Area: 6 × 9 = 54 sq ft. Check: the drawing area is 24 sq in., and 24 × 1.5² = 24 × 2.25 = 54. ✓
