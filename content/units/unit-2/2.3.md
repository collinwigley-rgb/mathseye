# 2.3 — Understand Proportional Relationships: Equivalent Ratios

Source: Lesson 2-3 student pages, 2-3 Additional Practice (pp. 21–22) · Built: 2026-11-03

## In one sentence
Two quantities are **proportional** when every pair has the same ratio y/x. Check every row of the table; if one row is off, it's not proportional.

## Key concepts and vocabulary
| Term | Plain meaning | Tiny example |
| --- | --- | --- |
| Proportional relationship | All ratios y/x are equal | 2→5, 4→10, 6→15 (all 2.5) |
| Proportion | An equation saying two ratios are equal | 3/8 = 9/24 |
| Constant factor | The number every x is multiplied by to get y | ×4: {1,3,5} → {4,12,20} |
| Not proportional | Some y/x is different, or there's a starting amount | Salami: 66, 96, 126 Calories (a base amount from the bread) |
| Enlargement / scale | Every length multiplied by the same factor | puzzle piece 4 → 7, so every length × 7/4 |

**Big idea:** proportional means "y is always the same number times x." Squares are a trap: the area of a square is NOT proportional to its side (4, 9, 16 vs 2, 3, 4), but the perimeter is.

## Problem profile
| Type | Given → asked | Numbers | Format | Share |
| --- | --- | --- | --- | --- |
| A. Is it proportional? (table) | x/y table with 3–5 rows → yes/no + explain | whole numbers, decimals (5.25 → 252), sometimes 1 row off (7→79 among ×5s) | explain | ~35% |
| B. Complete the table | proportional table with blanks → fill in | friendly factors (×3, ×25, ÷2) | fill-in | ~15% |
| C. Find a missing value | proportional data + new x (or y) → the value | sometimes fractions (x = 5/3) | typed | ~20% |
| D. Unit rate in context | one data point (9 floors, 135 ft) → unit rate + its meaning → scale up | whole numbers | multi-part | ~10% |
| E. Same relationship? | two tables → do they share the same ratio? | big vs. small numbers (160→360 and 2→4.5) | explain | ~10% |
| F. Select all true | table + 5 statements (the ratio is 8? when x = 20, y = ?) | decimals | select-all | ~10% |

**Traps the sheet sets on purpose:** a table where y/x looks right for the first rows but one row breaks the pattern; powers (x² or x³) disguised as growth; a base fee (+ a starting amount); a ratio written upside down (y/x vs x/y, as in Katerina's error).

## Methods: ways to attack it

### Method 1: "Divide every row" (the y/x test)
1. For **each row**, compute y ÷ x.
2. All the same? Proportional, and that number is the unit rate.
3. Any different? Not proportional. Point to the row that breaks it.
**Memory hook:** "Every row, same number, or no."
**Check it:** did you check *every* row, not just the first two?

### Method 2: "Find the multiplier" (scale factor)
Look across: what do you multiply x by to get y? Use the same multiplier on every row. For enlargements: new ÷ old = factor, then multiply every length by it.

### Method 3: Does it start at zero?
Ask: "If x were 0, would y be 0?" Zero dozen eggs should cost $0. A sandwich with zero salami still has bread Calories, so it's not proportional.
Not proportional also shows up as "same jump each row, but y/x changes."

### Method 4: Cross-multiply (for a missing value or a proportion)
a/b = c/d → a × d = b × c. Useful for "576 towers → how many customers?"

## Guiding questions (homework help)
1. "What's y ÷ x for the first row? Now the second?"
2. "Did every row give the same number?"
3. "If x were zero, what would y be? Does that make sense here?"
4. "What does that unit rate *mean* in this story?" (feet per floor)
5. For select-all: "Test each statement one at a time with your unit rate."

## Common mistakes
| Mistake | What it looks like | Nudge |
| --- | --- | --- |
| Checks only 2 rows | misses the broken last row | "Did you test all of them?" |
| Same jump means proportional | +30 each row, but there's a start amount | "Is y ÷ x the same every time?" |
| Flips the ratio | says x/y when they asked y/x | "Which one is on top in y/x?" |
| Area vs. side | calls the square area proportional | "Side ×2: does the area ×2 too?" |
| Explains without numbers | "because it goes up" | "Show me the ratios that prove it." |

## Variant recipes
- **A:** a 4-row table with y = kx (k in 1.5..12), and 50% of the time change one y by ±1..5, or use y = kx + b.
- **B:** a proportional table with 2 blanks; k a whole number or .5/.25.
- **C:** k plus a new x that's a fraction (x = 2/3, 5/3) or a decimal.
- **D:** "N things measure M total" → unit rate → total for a new N.
- **E:** two tables with the same k but very different scales, or k differing by a little (2.25 vs 2.2).
- **F:** 5 statements: the ratio is k, the ratio is 1/k (trap), y for a given x, x for a given y, the next row value.

## Worked example (original)
*Is this proportional? x: 2, 5, 8 → y: 7, 17.5, 28.*
1. 7 ÷ 2 = 3.5. 17.5 ÷ 5 = 3.5. 28 ÷ 8 = 3.5.
2. Every row gives 3.5, so yes, it's proportional. The constant is 3.5.
3. Check: x = 0 → y = 0, and that fits a ×3.5 pattern.
