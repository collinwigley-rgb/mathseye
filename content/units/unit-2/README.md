Find "how much for 1" (the unit rate), and every other question becomes multiply or divide.

## The thread that ties them together
```
2.1  unit rate with whole numbers and decimals   ($81.25 for 5 h → per 1 h)
2.2  same move, but the numbers are fractions   (3/4 mi in 1/6 h → per 1 h)
2.3  is the unit rate the SAME for every row?    (yes → proportional; that rate is k)
2.4  y = kx: k is the unit rate
2.5  graph: a straight line through (0, 0); the point (1, k)
2.6  decide IF it is proportional first (times or plus?)
2.8  scale drawings: actual = k × drawing; area uses actual sides
```

## One routine for the whole unit: "Get to 1"
1. **Label** the two quantities and decide which one goes on top ("per what?" goes on the bottom).
2. **Get to 1:** divide both by the bottom number.
3. **Scale up:** multiply that one-unit amount by what the problem asks for.
4. **Sanity check:** bigger amount → bigger answer? Units make sense?
