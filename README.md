# Mathseye

Math apps for 7th-grade pre-algebra. First up: **Math Facts**, a bedtime mental-math flash card app.

## Use it on the iPad
Open https://collinwigley-rgb.github.io/mathseye/ in Safari, tap **Share**, then **Add to Home Screen**. It works offline after the first load.

## Asking for changes
Open a GitHub Issue using the **Change request** template. Claude picks these up at the start of each session.

## Develop
```bash
npm install
npm run dev     # local server
npm test        # unit tests
npm run build   # production build in dist/
```
