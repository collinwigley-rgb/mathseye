# Color schemes

GENERATED by `tools/check_themes.py --write` from `tools/brand_themes.py`. Do not edit this file by hand; edit the table in `brand_themes.py`.

Thirteen schemes, grouped by band member. The student picks one on the home screen; the choice is saved on the device and shared by the app, study guide, and homework page.

## How to tune a color
1. Edit the row in `THEMES` in `tools/brand_themes.py` (hex values only).
2. Run `python3 tools/brand_themes.py && python3 tools/build_unit.py 2 <scratch-dir>` to regenerate the app CSS, `src/brand.ts`, and the static pages.
3. Run `python3 tools/check_themes.py --write`. It fails if any pair drops below the contrast limit or if generated files are out of date.
4. Look at it on the iPad in dark and light mode.

## Where the colors came from
Palettes are inspired by six seasonal color-analysis boards the owner shared, plus a Classic scheme that keeps the original ink-and-butter brand.
- **Sampled exactly from the image:** Dark Spring and Light Autumn swatches.
- **Matched by eye** (image not on disk): Dark Winter, Light Summer, Dark Summer, Light Spring.
- **Member signature colors** (Purple, Pastel Yellow, Sky Blue, Pastel Green, Peach, Pink): from the owner's written list of member colors. Each has a second color (accent 2) for gradients, stars and celebrations.
- **Original:** ink navy `#14111f` and butter yellow `#fceeaa`.
- **To assign a seasonal palette to a member:** change `None` to the member's name in its row in `THEMES`, regenerate, and it moves into that member's card.
- Scheme names are palette names. No scheme is tied to a person.

## Shared text colors (all schemes)
- Dark mode: text `#f1ecd8`, muted `#b4aac4`, text on accent `#1a1626`
- Light mode: text `#1b1730`, muted `#5b5570`
